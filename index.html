Apariencia y comportamiento

Tema oscuro
Activa el modo oscuro. Si lo desactivás, usá el modo claro (rosa pastel o blanco Vercel según el estilo).
VercelTheme
Estilo minimalista blanco/negro estilo Vercel, tanto para el modo claro como oscuro. Desactivado = estilo Cozy (rosa/lila).
Recarga forzada cada 5 días
Equivale a hacer Ctrl + Shift + R. Asegura que veas siempre la última versión y no queden datos viejos del localStorage.

Configuración externa (compartida)

El archivo config.js define los datos compartidos (atajos, proveedores, avisos, checklist, tutoriales). Editalo con cualquier editor de texto y recargá para aplicar los cambios a todos los usuarios.

Tutoriales

Activá el modo edición para crear tutoriales desde la web. Cada tutorial puede tener varios temas y partes.

Modo edición
Muestra botones para editar o eliminar tutoriales directamente desde las tarjetas.
